# Algoritmia

Este repositorio contiene tres carpetas de ejercicio de las sesiones de algoritmia en PSeInt.

## Estructura del proyecto

```text
algoritmia/
├── README.md
├── algoritmia-s1/
│   ├── EdadEnDias.psc
│   ├── PromedioNotas.psc
│   ├── Propinas.psc
│   ├── Saludo.psc
│   └── README.md
├── algoritmia-s2/
│   ├── Bisiesto.psc
│   ├── Parqueadero.psc
│   ├── Semaforo.psc
│   ├── ValidarEdad.psc
│   ├── ValidarRegistro.psc
│   └── README.md
├── algoritmia-s3/
│   ├── CajeroParqueadero.psc
│   ├── Calificaciones.psc
│   ├── FacturaRestaurante.psc
│   ├── Piramide.psc
│   ├── ValidarPIN.psc
│   └── README.md
└── .git/
```

## ¿Qué incluye cada carpeta?

### algoritmia-s1

- cálculo de edad en días
- promedio de notas
- propinas
- saludo básico

### algoritmia-s2

- bisiesto
- parqueadero
- semáforo
- validación de edad
- validación de registro

### algoritmia-s3

- cajero del parqueadero
- calificaciones
- factura de restaurante
- pirámide
- validación de PIN
